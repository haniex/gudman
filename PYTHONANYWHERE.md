# Публикация сайта на PythonAnywhere

Эта инструкция рассчитана на первый запуск. Можно попросить помощника сделать настройки после входа в аккаунт. Никому не отправляйте пароли в переписке.

## 1. Аккаунт и загрузка файлов

1. Зарегистрируйтесь на https://www.pythonanywhere.com/ или войдите в существующий аккаунт. Имя пользователя будет частью будущей ссылки: `https://ИМЯ.pythonanywhere.com/`.
2. Откройте вкладку **Files** в панели. Загрузите туда архив `avtoservice-motion.zip` (кнопка Upload a file).
3. Откройте **Consoles → Bash**. Введите:

```bash
cd ~
unzip -o avtoservice-motion.zip
```

Получится папка `/home/ИМЯ/avtoservice-motion`.

## 2. Создание веб-приложения

1. Откройте вкладку **Web**, нажмите **Add a new web app** и выберите ваш адрес.
2. Выберите **Manual configuration** и Python 3.10 или новее.
3. На странице Web откройте ссылку **WSGI configuration file**. Замените содержимое файла следующим кодом. Вместо `ВАШ_ЛОГИН` укажите имя аккаунта (в обеих строках пути, если потребуется):

```python
import sys
path = '/home/ВАШ_ЛОГИН/avtoservice-motion'
if path not in sys.path:
    sys.path.insert(0, path)
from wsgi_app import application
```

4. Сохраните файл и нажмите **Reload** на вкладке Web. Перейдите по адресу сайта, указанному вверху этой вкладки.
5. Проверьте сайт на компьютере и телефоне, отправьте тестовые заявки через обе формы. Для проверки базы в Bash введите:

```bash
cd ~/avtoservice-motion
python3 server.py list
```

Тестовые заявки и личные данные сохраняются в `data/requests.sqlite3`. База хранится отдельно от доступных веб-файлов; никому её не передавайте. Чтобы сохранить копию, скачайте её через вкладку Files в безопасное место.

## 3. Настройка почтовых уведомлений

Без настройки почты заявки будут попадать только в базу, а на странице будет предупреждение. Получатель уведомлений — `gudkovdanil181@gmail.com`.

1. В Gmail аккаунта-отправителя включите двухэтапную аутентификацию и создайте **пароль приложения** Google, если аккаунт позволяет. Обычный пароль Google не нужен.
2. В приватной Bash-консоли PythonAnywhere:

```bash
cd ~/avtoservice-motion
python3 setup_mail.py
```

Введите адрес Gmail отправителя и пароль приложения в приглашении (пароль не отображается). Это сохранит конфигурацию в приватном файле `~/.tochka_config.json`; не отправляйте его и не загружайте в публичные репозитории.
3. На вкладке Web нажмите **Reload**. Отправьте тестовую заявку и проверьте почту и папку «Спам». В консоли `python3 server.py list` показывает состояние отправки, но для чтения конфигурации при повторной отправке сначала укажите те же переменные окружения вручную либо выполните команду через Python:

```bash
cd ~/avtoservice-motion
python3 -c 'import wsgi_app, server; server.retry_unsent()'
```

`sent` означает, что SMTP-сервер принял письмо, а не гарантированную доставку. При сбое после приёма письма повтор может создать дубликат.

На бесплатном тарифе PythonAnywhere обычный внешний SMTP ограничен, но Gmail SMTP указан как исключение; возможны временные сбои, если IP-серверов Google меняются. См. https://help.pythonanywhere.com/pages/SMTPForFreeUsers/ .

## Ограничения

- Бесплатное веб-приложение может требовать периодического продления во вкладке Web; проверяйте срок действия в аккаунте.
- Это учебный прототип, не защищённая промышленная CRM. Перед настоящим публичным использованием настройте защиту от спама, резервное копирование, сроки хранения и политику обработки персональных данных.
- Не публикуйте пароли и файл базы. Локальные данные из старой версии не переносятся автоматически: если они нужны, их следует отдельно и безопасно перенести в новую папку проекта до запуска.
