# ТОЧКА СЕРВИС — сайт автосервиса

Учебный сайт с прайсом, заявками, 3D-просмотром и переключением темы. Первый экран показывает художественную реконструкцию Roadster 2026: движение по полуоткрытой рампе, переворот и четыре условные струи пара при посадке. Это не запись и не точная копия презентации. В автопарке модели BMW M4, Porsche 911, Audi S4 и BMW X5. У BMW M4, Porsche и Audi анимируются доступные детали колёс. У BMW X5 также отделяются двери, капот и багажник. При нажатии раздвигаются колёса, тормоза и доступные детали кузова; рядом появляется отдельная учебная модель двигателя с движущимися узлами. Это не двигатель выбранной машины. Капот и багажник у BMW M4, Porsche и Audi не отсоединяются.

## Быстрый запуск

Установите Python 3.10 или новее. Дополнительные библиотеки не нужны.

1. Распакуйте архив.
2. Откройте терминал в папке проекта.
3. Запустите `python server.py` (Windows: `py server.py`; macOS/Linux: `python3 server.py`).
4. Откройте http://127.0.0.1:8000 . Останавливайте сервер сочетанием Ctrl+C.

Не открывайте `index.html` напрямую: формам нужен запущенный сервер. Заявки сохраняются в `data/requests.sqlite3`. Даже без SMTP они записываются в базу, но письма не отправляются: пользователь увидит это после отправки.

### Простой локальный запуск с почтой

После создания пароля приложения запустите `python start_mail.py` (Windows: `py start_mail.py`; macOS/Linux: `python3 start_mail.py`). Введите почту отправителя, почту получателя и пароль приложения (при вводе пароль не отображается). Пароль не сохраняется в файле — потребуется вводить его при каждом запуске. Откройте сайт и отправьте тестовую заявку. Для PythonAnywhere используйте `setup_mail.py` и инструкцию `PYTHONANYWHERE.md`; его конфигурация не подключается к обычному `server.py`.

macOS / Linux (в этой же сессии терминала):

```bash
export SMTP_HOST=smtp.gmail.com
export SMTP_PORT=587
export SMTP_USER='адрес_отправителя@gmail.com'
export SMTP_PASSWORD='пароль_приложения'
export MAIL_TO='gudkovdanil181@gmail.com'
python3 server.py
```

Windows PowerShell:

```powershell
$env:SMTP_HOST='smtp.gmail.com'
$env:SMTP_PORT='587'
$env:SMTP_USER='адрес_отправителя@gmail.com'
$env:SMTP_PASSWORD='пароль_приложения'
$env:MAIL_TO='gudkovdanil181@gmail.com'
py server.py
```

Поддерживаются STARTTLS на порту 587 и SMTP SSL на порту 465. Если используется другой провайдер, укажите его сервер, порт, логин и пароль приложения; отправитель по умолчанию равен SMTP_USER (опционально SMTP_FROM). Доступность отправки зависит от настроек почтового провайдера. Для проверки отправьте тестовую заявку и проверьте почту и папку «Спам».

## Просмотр и повторная отправка

`python server.py list` — вывести обращения и статус писем в терминале. База содержит персональные данные: не делитесь ею, ограничьте доступ к файлу и не сохраняйте её в открытом репозитории. Статусы: `sent` — SMTP-сервер принял письмо (не гарантия доставки), `not_configured` — SMTP не настроен, `failed` — ошибка отправки, `pending` — отправка ещё не завершена.

`python server.py retry` — попробовать отправить все неотправленные письма заново с текущими SMTP-переменными. При сбое связи после приёма письма провайдером возможны дубликаты; перед повтором проверьте почту. Работа команд зависит от указанного DB_PATH (по умолчанию `data/requests.sqlite3`).

## Размещение

Пошаговая инструкция для PythonAnywhere находится в `PYTHONANYWHERE.md`. Новая версия использует папку `avtoservice-motion` и отдельную базу: старые заявки автоматически не переносятся.


Это рабочий локальный прототип; GitHub Pages размещает только статические файлы и не запустит Python, SQLite и SMTP. Для работы онлайн нужен сервер с Python, постоянным хранилищем базы и HTTPS; установите `HOST=0.0.0.0` и переменную `PORT` при запуске на таком сервере. Встроенный HTTP-сервер учебный, не предназначен для высоконагруженного продакшена. Для публичного запуска настройте защищённый reverse proxy/WSGI-сервер, резервное копирование, защиту от спама и ограничение запросов, хранение секретов и соблюдение требований к персональным данным; не публикуйте базу и учётные данные. Сервер не предоставляет публичный доступ к файлу БД, но ограничитель запросов здесь только локальный и сбрасывается при перезапуске.

## Состав

- `public/` — разметка, стили, анимация, логика форм и изображение.
- `server.py` — маршруты, проверка данных, SQLite, SMTP и команды обслуживания.
- `data/` — база создаётся автоматически при запуске; в архиве данных посетителей нет.

## О 3D-графике

В автопарке используются модели BMW, Porsche, Audi и BMW X5 (открытая модель BMW Car IT), а также отдельная учебная модель двигателя Innerscene (CC0); на первом экране — авторская реконструкция Roadster. Сцены используют студийное HDR-освещение. Использованы тени и студийное окружение. Модели стилизованные, а не фотореалистичные. Красно-чёрный визуал тормозного механизма создан генеративным ИИ и не является 3D-сценой. Чтобы получить фотореализм уровня референсов, потребуется подходящая высокополигональная модель с 4K PBR-текстурами и разрешением на использование. Файл `ATTRIBUTION.txt` содержит источники моделей.


## Разработка
Движение Roadster и вращение колёс привязаны к прокрутке; настройка уменьшения движения отключает анимацию. В автопарке нажмите на модель или выберите её клавишей Enter; перетаскивание вращает автомобиль. Нужны качественные GLB-модели с отдельными узлами для полноценной разборки. Кнопка темы сохраняет выбор в браузере. Фоновая сфера точек анимируется при обычных настройках; при уменьшении движения остаётся статичной.
